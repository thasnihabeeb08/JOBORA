# 🤖 AI-Powered Job Recruitment System

An AI-powered recruitment platform that connects **job seekers, companies, and administrators** in a single system. The platform streamlines job discovery, recruitment, application management, AI-based candidate-job matching, communication, and interview scheduling.

## ✨ Key Features

### 👤 Job Seeker Module

* 🔐 User registration and secure login
* 👤 Create and update personal profile
* 📄 Manage resume, skills, education, and experience
* 🔍 Search and browse available job opportunities
* 🎯 Receive AI-powered job recommendations
* 🤖 View AI-based job/candidate match scores
* 📝 Apply for jobs online
* 📊 Track application status
* 💾 Save/bookmark interesting jobs
* 💬 Communicate with companies through messaging
* ⭐ Submit feedback and ratings

### 🏢 Company Module

* 🔐 Company registration and login
* 🏢 Create and manage company profile
* 📢 Post new job vacancies
* ✏️ Edit, update, and manage posted jobs
* 📋 View and manage job applications
* 👤 Review candidate profiles and resumes
* 🤖 View AI-based candidate-job matching
* 📅 Schedule interviews with shortlisted candidates
* 💬 Communicate with job seekers
* 📊 Track recruitment/application status

### 🛡️ Admin Module

* 🔐 Secure administrator login
* 👥 Manage job seeker accounts
* 🏢 Manage registered companies
* 💼 Manage job postings
* 📋 Manage applications
* 📝 Manage blog content
* 🌟 Manage success stories
* ⭐ Review and manage user feedback
* 🛠️ Monitor and control overall platform activities

### 🤖 AI-Powered Features

* 🎯 AI-based job recommendations for job seekers
* 🔎 AI-based candidate-job matching
* 📊 Match score generation based on relevant candidate/job information
* 🧠 Intelligent recommendation to improve job discovery and recruitment

### 💬 Communication & Recruitment

* 💬 Real-time/user-to-user messaging
* 📅 Interview scheduling
* 📋 Application status tracking
* 🔔 Recruitment workflow management
* 🔄 Interaction between companies and job seekers

## 🧩 Main System Modules

| Module        | Main Responsibilities                                                   |
| ------------- | ----------------------------------------------------------------------- |
| 👤 Job Seeker | Profile, job search, recommendations, applications, messaging, feedback |
| 🏢 Company    | Job posting, candidate management, AI matching, interviews, messaging   |
| 🛡️ Admin     | Users, companies, jobs, applications, blogs, success stories, feedback  |
| 🤖 AI Engine  | Recommendations and candidate-job matching                              |

## 🎯 Project Highlights

* **Three-role architecture:** Job Seeker, Company, and Admin
* **AI-assisted recruitment:** Intelligent recommendations and matching
* **End-to-end recruitment workflow:** From job posting and discovery to application and interview
* **Centralized administration:** Complete platform management through an admin module
* **Interactive communication:** Messaging between job seekers and companies
* **Application tracking:** Helps candidates monitor their recruitment progress
